### what's inside
- clock - shows the current time and date
- calendar - browse months, today gets highlighted
- stopwatch - start, stop, reset
- advent calendar - above three are okay,since i didn't make it look like i wanted to spend anything on christmas,i decided to find some random facts,so no money involved
- (why does the text block the numbers from 21-25 you ask? because i wanted to show you how much i worked here + i don't really want you accessing 21-25)
